# 🍉 合成大西瓜 · 桌面自动化

自动帮你玩斗鱼直播间的「合成大西瓜」互动玩法：打开直播间 → 点开游戏 → 自动投放水果 → 合成大西瓜 → 结束自动重开下一局。全程无人值守，跑一晚上攒战绩。

## 功能

- ✅ 全自动流程：进局、投放、结算、刷新重开（无需复活）
- ✅ 两种策略可切换：
  | 策略 | 说明 |
  |---|---|
  | **默认 ★ 鲁棒落点（推荐）** | 投放时做邻域三点评估，抗物理落点误差。实测 **5 局 1 个大西瓜**，唯一稳定出西瓜的配置 |
  | 默认2 · 纯 v1 | 旧版最优基线，仅做对照用 |
- ✅ 实时可视化：场地画布（水果/死亡线/决策点）、运行日志、战绩统计
- ✅ 匿名对局数据上报（可选）：帮助改进策略，不含账号与直播间信息

## 系统要求

- Windows 10/11（64 位）
- **任意 Chromium 系浏览器**（自动探测，无需手动配置）：
  - Microsoft Edge（**Windows 自带**，无 Chrome 也能用）✅
  - Google Chrome ✅ / Brave ✅
- 斗鱼账号（首次使用需扫码登录一次，之后自动复用）
- 安装：https://github.com/qlingzzmm01/watermelon-bot/releases/tag/v1.1.0
  点击下载名称为windows的解压包解压后即可使用

## 快速开始

1. 下载 `合成大西瓜自动化.7z` → 解压到任意目录（建议英文路径或桌面）
2. 双击 `合成大西瓜自动化.exe`
3. 粘贴一个**斗鱼直播间地址**（必须：软件不再内置任何直播间）：
   ```
   例如：https://www.douyu.com/4042402
   ```
4. 点 **▶ 开始自动合成**
5. 首次会弹出浏览器（自动选择 Chrome / Edge / Brave）→ 若未登录斗鱼请扫码登录 → 之后全自动

> 提示：软件会自动找到直播间里的「合成大西瓜」入口并进入。若直播间没有该玩法，请换一个开启了玩法的直播间。

## 使用建议

- 推荐保持策略 **「默认 ★ 鲁棒落点」**（已默认选中）
- 「无头模式」勾选后不显示浏览器窗口，后台运行，适合挂机
- 结束退出：点「■ 停止」再关窗口；直接关窗口也会自动清理浏览器

## 数据上报说明

软件默认**开启匿名上报**：每局结束后上传该局的得分/最高等级/西瓜数/合成路径等统计（用于作者优化策略）。
- **不采集**：直播间地址、斗鱼账号、cookies、任何个人信息
- 设备以随机匿名 ID 标识，无法反查使用者
- 可在界面「匿名上报对局数据」处**随时关闭**（关闭后完全不联网）

## 常见问题

| 问题 | 解决 |
|---|---|
| 双击没反应 | 确认解压完整（含 `_internal` 目录），勿直接运行压缩包内 exe |
| Chrome 没弹出来 | 若开着旧浏览器，先全部关闭再点开始；确认已装 Edge/Chrome/Brave（任一即可） |
| 提示找不到游戏 | 换一个正在开播且有「合成大西瓜」玩法的直播间 |
| 想换直播间 | 「■ 停止」后改地址再点开始 |
| 想切纯 v1 对照 | 策略区选「默认2 · 纯 v1」再开始 |
